Assessment Technology · In Daily Use

Speaking Evaluator

A Progressive Web App for real-time speaking assessment. Evaluators score against official rubrics while the tool flags where a student's performance in one area limits their overall result—making feedback faster and more consistent.

The Problem

Teachers conducting speaking assessments needed a replicable method to score against criteria rubrics in real time, during class, without relying on paper or complex software. The existing tools were either too heavy, too expensive, or required constant connectivity.

The Constraint

The tool had to run on teachers' personal devices, work reliably on inconsistent connections, and be immediately intuitive to evaluators who are focused on the student, not the interface.

What I Built

A Progressive Web App in vanilla JavaScript that streamlines real-time scoring against testing rubrics. The interface surfaces "band-capping alerts"—moments where a student's performance in one criterion (like grammar range) limits their overall band regardless of strengths elsewhere.

  • Core logic in vanilla JS with zero external dependencies
  • Works offline after initial load
  • Clean, distraction-free UI designed for evaluators under time pressure
  • Progressive Web App: installable for browsers, phones, and tablets without app stores

Why This Way

A framework would add weight and dependencies for a problem that is fundamentally about logic and interface clarity. The scoring algorithm is the product; the UI's job is to get out of the way. Vanilla JS keeps the bundle small, the performance predictable, and the maintenance straightforward. A robust reporting dashboard lets instructors evaluate progress for classes and students, and share that feedback.

Vanilla JS Testing Rubrics PWA Progressive Enhancement
Teacher Tool · My Daily Driver

Lesson Prepper

One pipeline from raw text to editable PowerPoint. Saves hours per week.

The Problem

Teachers spent hours per lesson manually formatting slides, copying text from PDFs, and adjusting layouts. The existing "digital curriculum" was a patchwork of documents that required constant reformatting.

The Constraint

No budget for proprietary LMS. No IT support. Teachers used whatever was on their laptops—mostly old versions of PowerPoint and MS Word, and free Google accounts. The solution had to be affordable, offline-capable, and output something teachers already knew how to use.

What I Built

A pipeline that evolved from a Google Gem + Python script into one tool: paste text → get structured lesson plan → customize slide layout → export editable PowerPoint. The AI handles the structure; the teacher handles the pedagogy.

  • Text ingestion—pasted from anywhere
  • AI-structured lesson plans with objectives, activities, and assessments
  • Customizable slide templates matching school branding
  • Direct, customizable and editable PowerPoint export—no starting from scratch

Why This Way

Teachers need PowerPoint files they can edit and adapt. By exporting to a format they already own, I removed the adoption barrier entirely. The AI structures the content; the PowerPoint is the deliverable.

Linguistic Reference · Applied Linguistics

Khmer Learns English

A reference site documenting 25 L1-to-L2 transfer patterns for Cambodian English learners. Covers phonology, grammar, and pragmatics with proficiency bands, dialect notes, and classroom-ready activities.

The Problem

English teachers in Cambodia reach for generic ESL worksheets because there's no centralized reference for how Khmer phonology, grammar, and pragmatics specifically shape learner errors. Without an L1-aware resource, teachers waste time diagnosing what are actually predictable transfer patterns—and students get corrections that don't address the root cause.

The Constraint

The resource had to be immediately useful to teachers with no linguistics background. No jargon without explanation. No theory without classroom application. It also had to load fast on low-end devices and work offline after first visit, since many teachers access materials on personal phones with inconsistent connectivity.

What I Built

A reference site that catalogs 25 documented L1-to-L2 transfer patterns organized by domain—phonology, grammar, and pragmatics. Each pattern includes a plain-language explanation, example errors, the Khmer-L1 root cause, proficiency-band guidance, and a ready-to-use classroom activity. The site is built in vanilla JavaScript with a Material Design interface for clean, scannable reference during lesson prep.

  • 25 transfer patterns with evidence-based explanations
  • Organized by domain: phonology, grammar, pragmatics
  • Proficiency bands and dialect notes for each pattern
  • Classroom-ready activities tied to every entry
  • Built as a Progressive Web App for offline reference

Why This Way

Teachers don't need another ESL worksheet repository. They need diagnostic insight—the "why" behind a learner's error. By documenting transfer patterns with Khmer-L1 roots, the site shifts the teacher's mindset from "what's wrong" to "what's predictable." Vanilla JS keeps the bundle small and the PWA installable; Material Design components provide a familiar, scannable reading experience without framework overhead.

Curriculum Design

Web Dev Fundamentals

A full syllabus teaching HTML5, CSS3, and JavaScript to secondary students or adult learners. Project-based, no prior experience needed.

The Problem

Students in introductory coding courses often copy syntax without understanding how it works. When they hit an error or need to switch tools, they lack the mental models to reason through the problem. They can follow tutorials but struggle to build independently.

What I Built

A scaffolded curriculum that teaches HTML, CSS, and JavaScript through foundational concepts first. Students learn pattern recognition, abstraction, and decomposition alongside syntax. Modules progress from basic markup to DOM manipulation, all in vanilla JS, with the rationale for when and why to use advanced tools built in.

Designed for secondary students or adult learners with no prior experience.

Why This Way

When a student writes CSS and watches a div change color, they see cause and effect immediately. Frameworks abstract away that causality. By starting with vanilla JS, students own the logic before they inherit someone else's abstractions.
